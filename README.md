# 🛍️ Student Mini Marketplace

A student-focused marketplace where college students can buy and sell useful items such as books, electronics, stationery, and other student essentials.

## 🚀 Features

- 🔍 Search products
- 🗂️ Filter products by category
- 🛒 Add products to cart
- ❤️ Add products to favorites
- ➕ Add new products
- 💾 Local Storage
- 🌙 Dark mode
- 📱 Responsive design

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Local Storage

## ▶️ How to Run

1. Download or clone the repository.
2. Open `index.html` in VS Code.
3. Open `index.html` in Chrome.
